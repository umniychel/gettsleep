# GettSleep PMS — Информационная система управления хостелом

## Быстрый старт

### 1. Установка Python и Django

Убедитесь, что у вас установлен Python 3.10+:
```
python --version
```

Установите зависимости:
```
pip install -r requirements.txt
```

### 2. Инициализация базы данных

```
python manage.py migrate
```

### 3. Загрузка тестовых данных (необязательно)

```
python manage.py seed_data
```

Это создаст пользователей, капсулы и тестовые бронирования.

### 4. Создание суперпользователя (если не использовали seed_data)

```
python manage.py createsuperuser
```

### 5. Запуск сервера

```
python manage.py runserver
```

Откройте браузер: **http://127.0.0.1:8000/**

## Разделы системы

### 🏠 Дашборд (`/dashboard/`)
- Общая статистика: капсулы, бронирования, задачи
- Карта текущей занятости капсул
- Последние бронирования и задачи уборки

### 📅 Бронирования (`/bookings/`)
- Список всех бронирований с фильтром и поиском
- Создание нового бронирования (новый или существующий гость)
- Расчёт стоимости в реальном времени (капсула × часы + услуги)
- Оформление заезда / выезда (автоматически создаёт задачу уборки)
- Отмена бронирования

### 🛏 Капсулы (`/rooms/`)
- Сетка всех капсул с текущими статусами
- Изменение статуса прямо из списка
- Добавление и редактирование капсул
- История бронирований по капсуле

### 🧹 Клининг (`/cleaning/`)
- Список задач на уборку с фильтром по статусу
- Кнопки «Начать» / «Готово» для горничных
- Автоматическое изменение статуса капсулы при завершении
- Ручное создание задач

### 📊 Отчёты (`/reports/`)
- Выручка за месяц и сегодня
- Загрузка номерного фонда
- График выручки за 14 дней (Chart.js)
- Источники бронирований
- Журнал аудита всех действий

### ⚙ Администрирование (`/admin/`)
- Django Admin: полное управление всеми объектами
- Управление пользователями и ролями
- Просмотр журнала аудита

## Смена базы данных на PostgreSQL

В `gettsleep_pms/settings.py` замените секцию `DATABASES`:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'gettsleep',
        'USER': 'postgres',
        'PASSWORD': 'yourpassword',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

Установите драйвер: `pip install psycopg2-binary`
